# Data

The library is the 250k drug-like ZINC subset used by Gómez-Bombarelli et al. (2018), distributed in the
[chemical_vae](https://github.com/aspuru-guzik-group/chemical_vae) repository. It is not copied here.

```bash
curl -L -o data/zinc250k.csv \
  https://raw.githubusercontent.com/aspuru-guzik-group/chemical_vae/master/models/zinc_properties/250k_rndm_zinc_drugs_clean_3.csv
```
